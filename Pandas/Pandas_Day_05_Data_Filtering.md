## 1. 오늘의 학습 목표

Day05에서는 DataFrame에서 **조건에 맞는 데이터만 골라내는 방법**을 학습했다.

광고 데이터 분석에서는 전체 데이터를 무조건 확인하기보다,

- 세션이 충분한 캠페인
- 주요 이벤트율이 높은 캠페인
- 특정 플랫폼의 캠페인
- 여러 조건을 동시에 만족하는 캠페인

처럼 분석 목적에 맞는 데이터를 선택하는 것이 중요하다.

오늘 학습한 핵심 구조는 다음과 같다.

```text
DataFrame
↓
조건 만들기
↓
조건에 맞는 행 선택
↓
필요한 데이터만 확인
↓
분석
```

---

# 2. 실습 데이터 만들기

광고 캠페인 데이터를 DataFrame으로 만들었다.

```python
import pandas as pd

data = {
    "platform": ["Naver", "Naver", "Google", "Google", "Kakao"],
    "campaign": ["민사_A", "민사_B", "민사_C", "민사_D", "민사_E"],
    "sessions": [1000, 700, 1200, 800, 500],
    "key_events": [120, 105, 150, 72, 60]
}

df = pd.DataFrame(data)

df
```

---

# 3. 주요 이벤트율 계산

`key_events`와 `sessions`를 이용하여 주요 이벤트율 컬럼을 만들었다.

```python
df["key_event_rate"] = df["key_events"] / df["sessions"] * 100

df
```

주요 이벤트율은 다음과 같다.

| 캠페인 | 세션 | 주요 이벤트 | 주요 이벤트율 |
|---|---:|---:|---:|
| 민사_A | 1000 | 120 | 12.0% |
| 민사_B | 700 | 105 | 15.0% |
| 민사_C | 1200 | 150 | 12.5% |
| 민사_D | 800 | 72 | 9.0% |
| 민사_E | 500 | 60 | 12.0% |

---

# 4. 기본 조건 필터링

## 세션이 800 이상인 캠페인

```python
df[df["sessions"] >= 800]
```

### 해석

```text
df
→ 전체 DataFrame

df["sessions"] >= 800
→ 각 행의 sessions가 800 이상인지 확인

df[조건]
→ 조건이 True인 행만 선택
```

즉,

```python
df[df["sessions"] >= 800]
```

은

> 세션이 800 이상인 행만 가져온다.

는 의미이다.

---

# 5. True / False 조건 확인

다음 코드를 실행하면 각 행이 조건을 만족하는지 확인할 수 있다.

```python
df["sessions"] >= 800
```

개념적으로 다음과 같은 결과가 만들어진다.

```text
민사_A → True
민사_B → False
민사_C → True
민사_D → True
민사_E → False
```

따라서,

```python
df[df["sessions"] >= 800]
```

을 실행하면 `True`인 행만 DataFrame으로 가져온다.

# 6. 주요 이벤트율 조건 필터링

## 주요 이벤트율이 10% 이상인 캠페인

```python
df[df["key_event_rate"] >= 10]
```

## 주요 이벤트율이 12% 이상인 캠페인

```python
df[df["key_event_rate"] >= 12]
```

주요 이벤트율을 기준으로 성과가 높은 캠페인만 골라낼 수 있다.

---

# 7. 문자열 조건 필터링

숫자뿐만 아니라 문자열을 기준으로도 데이터를 필터링할 수 있다.

## Naver 플랫폼만 선택

```python
df[df["platform"] == "Naver"]
```

여기서 중요한 것은 `==`이다.

```python
platform = "Naver"
```

는 값을 할당하는 것이다.

반면,

```python
df["platform"] == "Naver"
```

는 값이 `"Naver"`와 같은지 비교하는 것이다.

### 정리

```text
=
→ 값을 대입

==
→ 같은지 비교
```

---

# 8. 여러 조건 동시에 사용하기

조건이 하나가 아니라 두 개라면 `&`를 사용할 수 있다.

## Naver이면서 세션이 500 이상인 캠페인

```python
df[
    (df["platform"] == "Naver")
    & (df["sessions"] >= 500)
]
```

구조:

```text
조건 1
+
조건 2
↓
&
↓
조건 1 AND 조건 2
```

즉, 두 조건을 **모두 만족하는 행**을 선택한다.

---

# 9. 광고 분석에 여러 조건 적용

## 주요 이벤트율이 10% 이상이고 세션이 700 이상

```python
df[
    (df["key_event_rate"] >= 10)
    & (df["sessions"] >= 700)
]
```

이런 방식으로 분석 목적에 맞는 캠페인만 추출할 수 있다.

# 10. 조건을 변경하여 데이터 탐색

조건의 숫자를 변경하면 분석 대상도 달라진다.

## 세션 1000 이상

```python
df[df["sessions"] >= 1000]
```

## 주요 이벤트율 15% 이상

```python
df[df["key_event_rate"] >= 15]
```

## 세션 700 이상 + 주요 이벤트율 15% 이상

```python
df[
    (df["sessions"] >= 700)
    & (df["key_event_rate"] >= 15)
]
```

조건을 변경하면서 결과가 어떻게 달라지는지 확인했다.

# 11. Day05 Challenge

다음 조건을 만족하는 캠페인만 선택한다.

> 세션이 700 이상이고 주요 이벤트율이 12% 이상인 캠페인

# 12. 오늘 배운 핵심 문법

## 여러 조건 필터링

# 13. 분석가 관점에서 이해하기

오늘 배운 필터링은 단순한 문법이 아니라 **분석 대상을 정의하는 과정**이다.

예를 들어 캠페인이 10,000개 있다면 모든 캠페인을 똑같이 확인하기보다,

```text
전체 캠페인
↓
세션이 충분한 캠페인
↓
성과가 좋은 캠페인
↓
집중 분석
```

과 같이 분석 목적에 맞게 대상을 좁힐 수 있다.

예:

```python
df[
    (df["sessions"] >= 700)
    & (df["key_event_rate"] >= 12)
]
```

이 코드는 단순히 데이터를 출력하는 것이 아니라,

> **"트래픽도 충분하고 주요 이벤트율도 높은 캠페인을 분석 대상으로 선정한다."**

라는 분석가의 조건을 코드로 표현한 것이다.
