# 2. Notion 이론 정리

## 2-1. 조건에 맞는 데이터 선택

Pandas에서는 조건식을 이용해서 원하는 행만 선택할 수 있다.

```python
df[df["sessions"] >= 500]
```

위 코드는 `sessions`가 500 이상인 행만 선택한다.

즉,

```text
전체 데이터
↓
sessions >= 500
↓
조건을 만족하는 행만 선택
```

과 같은 방식이다.

---

## 2-2. 비교 연산자와 Pandas

Python에서 배운 비교 연산자를 Pandas에서도 그대로 사용할 수 있다.

| 연산자 | 의미 |
|---|---|
| `>` | 초과 |
| `>=` | 이상 |
| `<` | 미만 |
| `<=` | 이하 |
| `==` | 같다 |
| `!=` | 같지 않다 |

예를 들어:

```python
df[df["key_events"] >= 100]
```

이라고 하면 주요 이벤트가 100 이상인 캠페인만 선택할 수 있다.

---

## 2-3. 새로운 컬럼 만들기

Pandas에서는 기존 컬럼을 이용하여 새로운 컬럼을 만들 수 있다.

예를 들어 주요 이벤트율을 계산한다면:

```python
df["key_event_rate"] = df["key_events"] / df["sessions"] * 100
```

기존의

- `sessions`
- `key_events`

컬럼을 이용해서

- `key_event_rate`

라는 새로운 컬럼을 만든 것이다.

이런 컬럼을 **파생 컬럼**이라고 생각하면 된다.

---

## 2-4. 광고 데이터 분석에서의 활용

광고 데이터를 다음과 같이 가지고 있다고 생각할 수 있다.

```python
data = {
    "campaign": ["민사_A", "민사_B", "민사_C", "민사_D"],
    "sessions": [1000, 700, 500, 300],
    "key_events": [120, 105, 80, 20]
}
```

DataFrame을 만든 뒤:

```python
df = pd.DataFrame(data)
```

주요 이벤트율을 계산하면:

```python
df["key_event_rate"] = df["key_events"] / df["sessions"] * 100
```

결과적으로 캠페인별 분석 지표를 DataFrame 안에 저장할 수 있다.

## 파생 컬럼 생성

```python
df["key_event_rate"] = df["key_events"] / df["sessions"] * 100

# 5. 광고 데이터 분석 관점에서 이해하기

오늘 배운 내용은 단순한 Pandas 문법보다 **실제 데이터 분석 과정**에서 중요하다.

예를 들어 광고 캠페인이 수천 개 있다면 모든 캠페인을 하나씩 확인하는 것이 아니라,

```text
광고 데이터
↓
DataFrame 생성
↓
필요한 지표 계산
↓
파생 컬럼 생성
↓
조건에 맞는 데이터 필터링
↓
분석 대상 캠페인 확인
```

과 같은 방식으로 데이터를 빠르게 분석할 수 있다.

---

# 6. 오늘의 핵심 정리

### `df[조건]`

조건에 맞는 행을 선택한다.

```python
df[df["sessions"] >= 500]
```

### `df["새로운 컬럼"] = 계산식`

기존 데이터를 이용해 새로운 컬럼을 만든다.

```python
df["key_event_rate"] = df["key_events"] / df["sessions"] * 100
```

### 핵심 사고방식

> **Pandas는 데이터를 하나씩 반복해서 처리하기보다, DataFrame의 여러 행을 한 번에 계산하고 조건에 따라 필요한 데이터를 선택할 수 있게 해준다.**

---

# 7. 오늘의 실무 연결

오늘 배운 내용을 실제 마케팅 데이터 분석 업무에 연결하면 다음과 같다.

```text
CSV / 광고 데이터
        ↓
DataFrame
        ↓
컬럼 확인
        ↓
분석 지표 계산
        ↓
파생 컬럼 생성
        ↓
조건 필터링
        ↓
성과가 좋은 캠페인 / 문제가 있는 캠페인 확인
```

앞으로 Pandas에서는 이러한 **데이터 가공 → 지표 생성 → 조건 필터링 → 집계** 흐름을 반복적으로 연습할 예정이다.
