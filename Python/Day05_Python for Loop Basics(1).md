## 📚 핵심 문법

### 1. `for`문의 기본 구조

Python에서 `for`문은 리스트와 같은 여러 개의 데이터를 하나씩 꺼내 반복해서 처리할 때 사용한다.

```python
campaigns = ["민사_A", "민사_B", "민사_C"]

for campaign in campaigns:
    print(campaign)
```

실행 결과:

```text
민사_A
민사_B
민사_C
```

- `campaigns` → 반복할 데이터가 들어 있는 리스트
- `campaign` → 리스트에서 현재 꺼낸 값을 저장하는 변수
- `in` → `campaigns`에서 값을 하나씩 가져온다는 의미
- `print(campaign)` → 현재 값을 출력
- 리스트의 데이터 개수만큼 반복 실행

즉,

> `for campaign in campaigns:`에서 `campaign`은 리스트의 값을 하나씩 전달받는 **변수**이다.

---

### 2. 리스트의 값을 하나씩 출력하기

```python
platforms = ["Naver", "Google", "Kakao"]

for platform in platforms:
    print(platform)
```

실행 결과:

```text
Naver
Google
Kakao
```

`for`문을 사용하면 리스트의 데이터를 하나씩 꺼내서 같은 작업을 반복할 수 있다.

---

### 3. 반복 횟수는 데이터 개수에 따라 결정된다

```python
numbers = [100, 200, 300]

for number in numbers:
    print(number)
```

실행 결과:

```text
100
200
300
```

리스트에 값이 3개이므로 `print(number)`가 총 3번 실행된다.

따라서,

> `for`문은 리스트의 데이터를 처음부터 하나씩 꺼내 동일한 작업을 반복한다.

---

## 🟡 `for`문 + 비교 연산자

### 4. 반복하면서 조건 판단하기

광고 분석에서는 여러 캠페인의 지표를 하나씩 확인해야 한다.

```python
key_events = [120, 105, 80]

for event in key_events:
    print(event >= 100)
```

실행 결과:

```text
True
True
False
```

`event >= 100`은 비교 연산자이므로 결과가 `True` 또는 `False`인 `bool` 값으로 나온다.

즉,

> `for`문으로 여러 데이터를 하나씩 가져오고, 비교 연산자로 각각의 데이터를 판단할 수 있다.

---

## 🟡 `for`문 + 조건문

### 5. 세션 수를 기준으로 캠페인 평가하기

```python
sessions = [1000, 300, 700]

for session in sessions:
    if session >= 500:
        print("유입량 충분")
    else:
        print("유입량 부족")
```

실행 결과:

```text
유입량 충분
유입량 부족
유입량 충분
```

처리 흐름:

```text
sessions 리스트
↓
1000 → 500 이상 → 유입량 충분
↓
300 → 500 미만 → 유입량 부족
↓
700 → 500 이상 → 유입량 충분
```

---

### 6. `for`문 + `if / elif / else`

여러 캠페인의 주요 이벤트율을 반복해서 평가할 수도 있다.

```python
key_event_rates = [12, 8, 15]

for rate in key_event_rates:
    if rate >= 15:
        print("우수")
    elif rate >= 10:
        print("양호")
    else:
        print("개선 필요")
```

실행 결과:

```text
양호
개선 필요
우수
```

여기서 중요한 구조는 다음과 같다.

> `for` → 데이터를 하나씩 가져온다.  
> `if / elif / else` → 가져온 데이터를 조건에 따라 판단한다.

---

## 🔴 데이터 분석에서 `for`문이 필요한 이유

캠페인이 3개라면 직접 계산할 수도 있지만, 캠페인이 100개 또는 1,000개가 되면 하나씩 직접 처리하기 어렵다.

```text
캠페인 1
↓
계산

캠페인 2
↓
계산

캠페인 3
↓
계산

...

캠페인 100
↓
계산
```

이러한 반복 작업을 Python에서는 `for`문으로 자동화할 수 있다.

따라서,

> 반복문은 많은 데이터를 같은 방식으로 빠르게 처리하기 위한 기본적인 도구이다.

## 🏆 Day5 Challenge

### 문제 9. 여러 캠페인의 주요 이벤트율 계산

다음과 같은 광고 데이터가 있다고 가정한다.

```python
campaigns = ["민사_A", "민사_B", "민사_C"]
sessions = [1000, 700, 500]
key_events = [120, 105, 80]
```

각 캠페인의 주요 이벤트율 공식:

```text
주요 이벤트율 = key_events / sessions × 100
```

Day35에서는 아직 여러 리스트의 같은 위치에 있는 값을 연결하는 방법을 배우지 않았기 때문에, 먼저 각각의 값을 계산해 리스트로 만든 뒤 `for`문으로 출력하는 방식으로 접근할 수 있다.

```python
rate_a = 120 / 1000 * 100
rate_b = 105 / 700 * 100
rate_c = 80 / 500 * 100

key_event_rates = [rate_a, rate_b, rate_c]

for key_event_rate in key_event_rates:
    print(key_event_rate)
```

실행 결과:

```text
12.0
15.0
16.0
```

각 캠페인의 주요 이벤트율은 다음과 같다.

| 캠페인 | 세션 | 주요 이벤트 | 주요 이벤트율 |
| --- | ---: | ---: | ---: |
| 민사_A | 1,000 | 120 | 12% |
| 민사_B | 700 | 105 | 15% |
| 민사_C | 500 | 80 | 16% |

즉, 주요 이벤트 수 자체는 민사_A가 가장 많지만, **주요 이벤트율은 민사_C가 가장 높다.**
