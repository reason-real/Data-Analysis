# Day08 - 조건에 맞는 데이터 필터링

## 📌 학습 목표

- `for`문과 `if`문을 함께 사용하여 조건에 맞는 데이터를 선택할 수 있다.
- 리스트에서 특정 기준을 만족하는 값만 골라낼 수 있다.
- `range()`와 인덱스를 활용하여 여러 리스트의 데이터를 연결할 수 있다.
- 광고 캠페인 데이터를 조건에 따라 필터링하고 분석 결과를 만들 수 있다.

---

## 📚 핵심 개념

### 1. 조건에 맞는 데이터만 선택하기

리스트에 여러 데이터가 있을 때 모든 값을 확인하는 것이 아니라, 특정 조건을 만족하는 데이터만 골라낼 수 있다.

```python
rates = [5, 12, 8, 15, 3]

for rate in rates:
    if rate >= 10:
        print(rate)
```

실행 결과:

```text
12
15
```

- `for` : 리스트의 값을 하나씩 가져온다.
- `if` : 가져온 값이 조건을 만족하는지 판단한다.
- `>= 10` : 10 이상인지 확인한다.
- 조건이 `True`인 값만 출력된다.

---

### 2. `for` + `if`의 데이터 필터링 구조

```python
for 데이터 in 리스트:
    if 조건:
        실행할 코드
```

이 구조는 데이터 분석에서 매우 자주 사용된다.

예를 들어 광고 캠페인 중 세션이 500 이상인 캠페인만 찾을 수 있다.

```python
sessions = [1000, 300, 700, 450, 1200]

for session in sessions:
    if session >= 500:
        print(session)
```

실행 결과:

```text
1000
700
1200
```

즉,

**전체 데이터 → 하나씩 확인 → 조건 판단 → 조건을 만족한 데이터만 선택**

이라는 흐름이다.

---

### 3. 여러 리스트를 연결하기

캠페인 이름과 성과 지표가 서로 다른 리스트에 저장되어 있다면 `range()`와 인덱스를 이용해 같은 위치의 데이터를 연결할 수 있다.

```python
campaigns = ["민사_A", "민사_B", "민사_C", "민사_D"]
key_event_rates = [12, 8, 15, 4]

for i in range(4):
    print(campaigns[i], key_event_rates[i])
```

실행 결과:

```text
민사_A 12
민사_B 8
민사_C 15
민사_D 4
```

여기서 같은 `i`를 사용하기 때문에

- `campaigns[i]`
- `key_event_rates[i]`

가 서로 같은 캠페인의 데이터를 가리킨다.

---

### 4. 조건에 맞는 캠페인만 선택하기

```python
for i in range(4):
    if key_event_rates[i] >= 10:
        print(campaigns[i], key_event_rates[i])
```

실행 결과:

```text
민사_A 12
민사_C 15
```

이제 단순히 데이터를 출력하는 것을 넘어 **조건에 맞는 캠페인만 필터링**할 수 있다.

---

## 📊 광고 데이터 분석 예시

다음과 같은 광고 데이터가 있다고 하자.

```python
campaigns = ["민사_A", "민사_B", "민사_C"]
sessions = [1000, 700, 500]
key_events = [120, 105, 80]
```

주요 이벤트율은 다음과 같이 계산한다.

```python
key_event_rate = key_events[i] / sessions[i] * 100
```

이를 이용해 각 캠페인의 성과를 평가할 수 있다.

```python
for i in range(3):
    key_event_rate = key_events[i] / sessions[i] * 100

    if key_event_rate >= 15:
        print(campaigns[i], key_event_rate, "우수")
    elif key_event_rate >= 10:
        print(campaigns[i], key_event_rate, "양호")
    else:
        print(campaigns[i], key_event_rate, "개선 필요")
```

실행 결과:

```text
민사_A 12.0 양호
민사_B 15.0 우수
민사_C 16.0 우수
```

---

## 💡 핵심 사고방식

데이터 분석에서는 단순히 전체 데이터를 보는 것보다 **의미 있는 조건을 설정하고 필요한 데이터만 골라내는 것**이 중요하다.

예를 들어 캠페인이 10,000개라면 모든 캠페인을 하나씩 확인하는 것보다,

> 주요 이벤트율이 10% 이상인 캠페인만 확인한다.

와 같이 조건을 설정하는 것이 효율적이다.

```python
if key_event_rate >= 10:
    print(campaigns[i])
```

이러한 **필터링 사고방식**은 이후 `pandas`에서 데이터를 다룰 때도 그대로 연결된다.

---

## 📝 배운 점

- `for`문으로 여러 데이터를 반복해서 확인할 수 있다.
- `if`문으로 조건에 맞는 데이터만 선택할 수 있다.
- `range()`와 인덱스를 사용하면 여러 리스트의 같은 위치에 있는 데이터를 연결할 수 있다.
- 광고 데이터에서는 캠페인별 지표를 계산하고 조건에 따라 성과를 분류할 수 있다.
- 데이터 분석에서는 **조건을 정의하고 필요한 데이터를 추려내는 능력**이 중요하다.
