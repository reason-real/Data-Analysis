# 📚 핵심 개념

## Git

- 버전 관리 시스템
- 파일의 변경 이력을 저장하고 관리한다.

## GitHub

- Git 저장소를 온라인에서 관리하고 공유하는 서비스

## Repository

- 프로젝트를 저장하는 공간

## Commit

- 변경 사항을 하나의 기록으로 저장하는 작업

## Push

- Commit한 내용을 GitHub 원격 저장소에 업로드하는 작업

# 🎯 핵심 정리

- Git은 버전 관리 도구이다.
- GitHub는 Git 저장소를 온라인에서 관리하는 플랫폼이다.
- Commit 후 Push를 수행해야 GitHub에 반영된다.
